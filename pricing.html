Pertanyaan Umum

Bagaimana cara upgrade paket?

Klik tombol upgrade, lalu ikuti instruksi pembayaran. Setelah kami konfirmasi pembayaran, API key kamu otomatis di-upgrade dan masa aktifnya diperpanjang 1 tahun.

Apa yang terjadi kalau kuota habis?

Request akan ditolak dengan kode 429 sampai periode berikutnya dimulai, atau kamu upgrade ke paket yang lebih besar.

Apa yang terjadi kalau API key expired?

Request akan ditolak dengan kode 403. Perpanjang langganan untuk mengaktifkan kembali.
